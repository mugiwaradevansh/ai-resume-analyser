## 🌟 Introduction

**AI Resume Analyzer** is a cutting-edge web application designed to help job seekers stand out. leveraging the latest web technologies to parse, analyze, and provide actionable feedback on resumes. Built with performance and user experience at its core, it offers a seamless interface to unlock your career potential.

## ✨ Features

- **📄 Smart PDF Parsing**: Instantly extract and structure data from resume PDFs.
- **🤖 AI-Powered Analysis**: Get deep insights and scoring based on industry standards using **Puter.js AI** capabilities.
- **⚡ Lightning Fast**: Powered by **Vite** and **React Router v7** for instant page loads and transitions.
- **🎨 Beautiful UI**: Crafted with **Tailwind CSS v4** for a stunning, responsive, and modern aesthetic.
- **☁️ Cloud Integrated**: Seamless file handling and authentication via **Puter.js**.

## 🛠️ Tech Stack & Advantages

This project is built with a carefully curated stack to ensure scalability, performance, and developer experience.

| Tech | Why We Use It |
| :--- | :--- |
| **React Router v7** | The standard for routing in React. Provides nested routing, loaders, and actions for a robust SPA experience. |
| **Zustand** | A small, fast, and scalable bearbones state-management solution. Simplifies global state without boilerplate. |
| **Tailwind CSS v4** | A utility-first CSS framework for rapidly building custom user interfaces. V4 brings even more performance and flexibility. |
| **TypeScript** | Adds static typing to JavaScript, reducing bugs and improving code quality and maintainability. |
| **Puter.js** | The operating system for the internet. Handles **Auth**, **File Storage**, and **AI** integration seamlessly. |
| **Vite** | Next Generation Frontend Tooling. Instant server start and lightning-fast HMR (Hot Module Replacement). |

## 🚀 Getting Started

Follow these steps to set up the project locally.

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

1.  **Clone the repository**
    ```bash
    git clone https://github.com/yourusername/ai-resume-analyzer.git
    cd ai-resume-analyzer
    ```

2.  **Install dependencies**
    ```bash
    npm install
    ```

3.  **Start the development server**
    ```bash
    npm run dev
    ```

4.  **Open your browser**
    Navigate to `http://localhost:5173` to see the app in action!
